Features

Quiet OCR, done locally.

Point it at a folder once and it handles the rest in the background.

Per-folder watch rules

Each rule has its own input folder, output location, filename suffix and recognition settings. Output goes next to the original or to a separate folder.

Real, searchable text layer

The original page image is kept and an invisible text layer is added, so Spotlight and Preview can search and select the words. An optional plain text file can be written alongside.

Apple Vision recognition

Choose Fast or Accurate, toggle language correction, and pick languages from the list Vision supports. Leave them unchecked to detect the language automatically.

Safe with your originals

Output is written to a temporary file and moved into place, so a failure never leaves a partial PDF. Originals are only trashed if you turn that on, and go to the Trash, not oblivion.

Waits for finished files

Folders are scanned every 3 seconds, and a file is processed only once its size and date are stable. Existing files are left alone until you choose Process Now.

Private, no network

It uses only Apple frameworks, has no analytics and makes no network connections. PDFs that already contain text and password-protected PDFs are logged as skipped.

Install

Up and running in a minute.

WatchFolderOcr is open source and not notarized with a paid Apple Developer ID, so macOS needs one extra step the first time.

  1. Download WatchFolderOcr-macOS.zip and unzip it.
  2. Move WatchFolderOcr.app to your Applications folder.
  3. Clear the quarantine flag once, then right-click the app and choose Open:
    xattr -cr /Applications/WatchFolderOcr.app
  4. No special permissions are required you only choose the folders to watch in a standard open panel, and "Launch at login" is optional under System Settings General Login Items.

FAQ

Questions, answered.

Is WatchFolderOcr really free and open source?

Yes. It is released under the MIT license and the full source is on GitHub. There are no ads, accounts or paid tiers an optional Support button links to Ko-fi if you want to chip in.

What permissions does it need?

None beyond the folders you pick. It does not request Accessibility, Screen Recording, Microphone or Camera access. If you enable Launch at login, it registers as a login item that you can review in System Settings.

Where is my data stored?

Your documents stay in the folders you choose, and converted files are written to the output location you set. Watch rules and folder bookmarks are kept in the app's UserDefaults on your Mac, and the log shows your last 500 files.

Why isn't the app notarized?

Notarization requires a paid Apple Developer account, and this is a free project. Right-click the app and choose Open once to get past Gatekeeper, or build it yourself from source with Xcode.

Was this written by AI?

Yes. WatchFolderOcr was generated by Claude Code from a written spec as a clean-room reimplementation, with no code or assets from any commercial app. The full source is on GitHub under MIT, so you can read every line before you run it. It has had less human review than a hand-written app, so bug reports are welcome.
